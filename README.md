# ModaFácil PI Etapa 6

Projeto Integrador desenvolvido no curso Técnico em Desenvolvimento de Sistemas do SENAC.

Nesta etapa, o sistema desktop ModaFácil foi refatorado com aplicação dos princípios SOLID, separação de responsabilidades, padrão Repository e injeção de dependência.

## Tecnologias

* Java 17
* Java Swing
* JDBC
* MySQL
* Apache Ant
* NetBeans

O arquivo `Entrega_Etapa6_ModaFacil.zip` contém o projeto refatorado, o projeto desktop anterior, o relatório da atividade e o documento do projeto.
